说明

每个报告都是一次可复现的验收：判据先写死，跑完再看结果。报告里的耗时、合规数都是实测输出， 不是估算，也不是挑出来好看的那部分。原始脚本在仓库 scripts/ 下，都能重跑； 检索那份还带一个 --verify 开关，用来检查标准答案本身有没有标错。
